# AI Team Core

**Pregunta como siempre. Construye como un equipo profesional.**

AI Team Core ayuda a convertir ideas y consultas en productos, experiencias, mockups, planes técnicos y resultados revisados. El usuario explica lo que necesita con sus propias palabras; no tiene que aprender prompting ni conocer las skills internas.

## Qué aporta

- Producto e inteligencia artificial.
- UX, flujos, wireframes y mockups.
- Arquitectura, implementación y planificación.
- Pruebas, calidad, seguridad y revisión.
- Preguntas aclaratorias cuando falta información decisiva.

## Uso

Después de instalar el plugin, iniciar una conversación nueva y escribir la consulta normalmente:

> Tengo una idea para un asistente con IA que ayude a nuestros clientes, pero no sé cómo diseñarlo.

## Límites

El plugin no comparte conversaciones, proyectos, memoria ni credenciales. No incluye conectores ni MCP y no realiza acciones externas sin autorización. Los mockups visuales dependen de las capacidades disponibles; cuando no existan, entrega un wireframe textual.
