NUVETIO 0.3.0 — GUÍA DE INICIO

Nuvetio es tu equipo experto de IA. Tú haces tus preguntas normalmente y sus departamentos especializados te ayudan a convertirlas en resultados profesionales de producto, diseño, inteligencia artificial e ingeniería.

IMPORTANTE

- Los instaladores permiten probar Nuvetio ahora en Codex CLI para Mac y Windows.
- No necesitas una cuenta de GitHub.
- Nuvetio no tiene costo adicional. Tu cuenta de ChatGPT o Codex puede tener sus propios límites o costos.
- Agent Skills es opcional y se instala solo si confirmas escribiendo SI.

INSTALACIÓN CON DOBLE CLIC

1. Descarga `Nuvetio-0.3.0-Setup.exe` para Windows o `Nuvetio-0.3.0.pkg` para Mac.
2. Abre el instalador y sigue Siguiente, Instalar y Finalizar.
3. Confirma el mensaje de instalación y abre una sesión nueva de Codex CLI.
4. Escribe normalmente lo que necesitas.

Puede aparecer una advertencia porque los instaladores todavía no están firmados. No descargan código remoto durante la instalación.

COMPLEMENTO OPCIONAL: AGENT SKILLS

Si quieres ampliar el equipo con 24 workflows de Addy Osmani, ejecuta el instalador Agent Skills de tu sistema desde installers y confirma escribiendo SI. Nuvetio funciona igual si decides no instalarlo.

PRIMERA PRUEBA

Tengo una idea para un producto con IA. Ayúdame a definirla y dime cuál debería ser el primer paso.

Nuvetio organizará la consulta como un equipo profesional: aclarará el objetivo, propondrá un flujo, evaluará riesgos y preparará próximos pasos concretos.

SI NECESITAS AYUDA

Comparte una captura del mensaje de error con la persona que te entregó Nuvetio. No compartas contraseñas, códigos de acceso ni información privada.
