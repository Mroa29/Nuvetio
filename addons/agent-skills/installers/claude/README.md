# Activar Agent Skills en Claude Code

1. Abre Claude Code en el proyecto donde quieres usar el complemento.
2. Escribe `/plugin marketplace add https://github.com/addyosmani/agent-skills.git`.
3. Revisa que el marketplace sea el repositorio de Addy Osmani y confirma.
4. Escribe `/plugin install agent-skills@addy-agent-skills` y confirma.
5. Abre una sesión nueva y prueba `/spec`, `/plan` o `/test`.

Estos pasos se ejecutan solo después de tu confirmación. Si no quieres conectar
el repositorio, cancela y Nuvetio seguirá funcionando con sus skills propias.
