# Nuvetio para Claude Code

Nuvetio organiza consultas cotidianas como un equipo profesional de producto,
IA, experiencia, ingeniería, calidad y departamentos consultivos. Usa esta
integración cuando la persona necesite convertir una pregunta en un plan,
mockup, decisión o entregable revisado.

La fuente canónica de la skill es
`plugins/nuvetio/skills/operate-nuvetio/SKILL.md`. El instalador puede copiarla
a `.claude/skills/nuvetio/` para el proyecto actual o a `~/.claude/skills/nuvetio/`
para el perfil del usuario. No sobrescribas un `CLAUDE.md` existente: agrega
solo una referencia a este bloque con autorización.

No compartas credenciales, conversaciones, memoria ni datos entre Claude,
Codex y ChatGPT. Antes de modificar archivos, conectar servicios o actuar fuera
del proyecto, explica el efecto y solicita autorización.
