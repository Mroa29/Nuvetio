Soluciones frecuentes

  • Antes de instalar Nuvetio, comprueba que Codex CLI esté instalado. Si la ventana dice que no lo encuentra, instala Codex y vuelve a ejecutar el instalador.
  • En Mac, si el sistema bloquea el archivo, haz clic derecho en Instalar-Nuvetio.command, elige Abrir y confirma una vez.
  • Después de instalarlo, inicia una sesión nueva de Codex CLI. Nuvetio quedará disponible sin crear una cuenta adicional.
