Soluciones frecuentes

  • Nuvetio se copia aunque Codex CLI no esté instalado. Puedes abrir Codex Desktop, instalar Codex CLI desde la guía oficial o usar Claude Code; vuelve a ejecutar el instalador para activar el runtime elegido.
  • Si Windows o Mac muestran una advertencia, es porque esta primera versión todavía no tiene firma digital. Revisa que hayas descargado el instalador desde la página oficial y continúa solo si reconoces el archivo.
  • Después de instalarlo, inicia una sesión nueva de Codex, Codex Desktop o Claude Code. Nuvetio quedará disponible sin crear una cuenta adicional.
  • Agent Skills es un complemento opcional y separado: actívalo solo si quieres sumar ese pack y confirma escribiendo SI.
  • El aprendizaje compartido es opcional: puedes responder “¿Te fue útil?” y revocar el consentimiento desde la configuración local.
