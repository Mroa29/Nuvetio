Privacidad

Cómo funciona la versión 0.5

Nuvetio contiene skills estáticas, adaptadores para Codex y Claude Code, instaladores nativos, departamentos consultivos y Agent Skills opcional con confirmación explícita. No recoge conversaciones completas ni modifica modelos automáticamente.

El aprendizaje local y el aporte compartido anonimizado requieren consentimientos separados. Ambos parten desactivados, se guardan localmente y pueden revocarse. Antes de crear un candidato se eliminan datos reconocibles como correos, teléfonos, tokens, rutas y secretos.

Si la persona activa el aporte compartido, el Worker recibe únicamente un candidato estructurado y redactado. Los candidatos se conservan hasta 90 días para revisión humana; los no aprobados se eliminan automáticamente y también se puede solicitar su eliminación. Una mejora aprobada solo se publica dentro de una nueva versión revisada: ningún candidato modifica un modelo o una skill automáticamente.

La redacción reduce riesgos, pero no promete anonimización perfecta. El backend compartido requiere configuración separada y una política de privacidad aprobada. Los productos anfitriones, como ChatGPT, Codex y Claude, procesan sus conversaciones según sus propios términos y políticas.
